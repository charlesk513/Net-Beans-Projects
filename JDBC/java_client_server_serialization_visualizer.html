How to Run & Execution Architecture

1. What Happens Under the Hood?

When clientObjectStreamWriter.writeObject(serialObj) is invoked:

  • Marker Interface: Java verifies that SerializableClass implements java.io.Serializable.
  • Header Handshake: Stream writes 0xACED (STREAM_MAGIC) and 0x0005 (STREAM_VERSION) header bytes.
  • Flattening: Reflection inspects non-transient fields (regno, surname, status) and serializes values to binary stream bytes.
  • Network TCP Transport: Bytes flow across port 50000 over TCP/IP socket.
  • Deserialization: On server side, readObject() allocates memory and reconstructs object instance on server Heap.

2. How to Run the Provided Java Code

  1. Create package directory charlesk.com.jdbc with Client.java, Server.java, and SerializableClass.java.
  2. Run Server.java first: Starts ServerSocket(50000) listening for incoming connections.
  3. Run Client.java second: Creates Socket("127.0.0.1", 50000) and opens streams.
